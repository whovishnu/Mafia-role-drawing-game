# Mafia Role Drawing Game

A private role-drawing tool for playing Mafia in person. Configure the number of Mafia, Doctors, Inspectors, and Villagers, then pass the device around so every player can secretly reveal their role.

## Play online

**[Launch the Mafia Role Drawing Game](https://whovishnu.github.io/Mafia-role-drawing-game/)**

## How to play

1. Choose the number of players for each role.
2. Select **Draw my secret role**.
3. Let the current player view and hide their role.
4. Pass the device to the next player.
5. Continue until every role has been drawn.

## Roles

- **Mafia** — Work together and eliminate a player each night.
- **Doctor** — Protect one player each night.
- **Inspector** — Investigate one player each night.
- **Villager** — Discuss, investigate, and vote to find the Mafia.

## Run locally

Download the repository and open `index.html` in any modern browser. No installation or build process is required.

## Technology

Built with standalone HTML, CSS, and JavaScript. Hosted with GitHub Pages.
